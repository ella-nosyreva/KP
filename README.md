## Индивидуальный вариант (Вариант 21)

- **Компоненты:** NIC, HDD, SSD.
- **Порядок записи:** компонент–время–значение, разделитель — пробел.
- **Тип последовательности (1):** записи идут по времени, на каждом отсчёте есть все три компонента.
- **Производный показатель:** темп прироста, %.
- **Параметры:** k = 3, L = 1.0, D = 10.
- **Правило состояния компонента:** если последние k значений Q строго возрастают → «УСТОЙЧИВЫЙ РОСТ», иначе → «НОРМА».
- **Правило инцидента:** ровно один компонент проблемный, а два других в «НОРМА».
- **Структура Incident:**

## 1. Алгоритм и блок-схема

### Описание алгоритма

1. Начало работы программы.
2. Ввод пяти тестовых значений для компонентов NIC, HDD и SSD.
3. Сохранение введённых значений.
4. Установка параметра `k = 3`.
5. Расчёт темпа прироста для каждого компонента по формуле:

   `Q[i] = 100 * (X[i] - X[i-k]) / X[i-k]`

6. Проверка полученных значений. Устойчивый рост определяется в том случае, если три последних значения `Q` строго возрастают.
7. Если условие устойчивого роста не выполняется, компоненту присваивается состояние «НОРМА». Если значений недостаточно для проверки, также присваивается состояние «НОРМА».
8. Проверка условий регистрации инцидента.
9. Вывод результатов расчётов и проверки на экран.
10. Завершение работы программы.

## 2. Контрольный пример: ручной расчёт

Для проверки работы программы используются пять тестовых значений для каждого компонента.

### Исходные данные

| Время | NIC | HDD | SSD |
|:---:|---:|---:|---:|
| 1 | 45.5 | 55.6 | 33.9 |
| 2 | 46.0 | 53.6 | 33.1 |
| 3 | 46.5 | 57.0 | 32.4 |
| 4 | 47.0 | 55.0 | 31.6 |
| 5 | 52.9 | 53.0 | 30.9 |

### Параметры расчёта

- `k = 3`;
- `L = 1.0`;
- `D = 10`.

### Формула расчёта

Темп прироста рассчитывается по формуле:

`Q[i] = 100 * (X[i] - X[i-k]) / X[i-k]`

где `X[i]` — текущее значение показателя, `X[i-k]` — значение показателя за три временных шага до текущего.

### Расчёт для NIC

`Q[4] = 100 * (47.0 - 45.5) / 45.5 = 3.30 %`

`Q[5] = 100 * (52.9 - 46.0) / 46.0 = 15.00 %`

### Расчёт для HDD

`Q[4] = 100 * (55.0 - 55.6) / 55.6 = -1.08 %`

`Q[5] = 100 * (53.0 - 53.6) / 53.6 = -1.12 %`

### Расчёт для SSD

`Q[4] = 100 * (31.6 - 33.9) / 33.9 = -6.78 %`

`Q[5] = 100 * (30.9 - 33.1) / 33.1 = -6.65 %`

### Результаты расчётов

| Компонент | Q[4], % | Q[5], % | Состояние |
|:---:|---:|---:|:---:|
| NIC | +3.30 | +15.00 | НОРМА |
| HDD | -1.08 | -1.12 | НОРМА |
| SSD | -6.78 | -6.65 | НОРМА |

Для проверки устойчивого роста требуется три последних значения `Q`. В данном примере для каждого компонента рассчитано только два значения, поэтому выполнить такую проверку невозможно. В программе при недостаточном количестве значений присваивается состояние «НОРМА».

Условие регистрации инцидента по результатам проверки не выполняется.
